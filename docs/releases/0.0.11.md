# GemPlayer 0.0.11

A test build of GemPlayer, a media player for Ubuntu Touch modelled on VLC
for Android. This build completes the video side of the app: a video player,
and around it a library that can be sorted, filtered, grouped and played as
a queue. The audio player and settings are still to come.

Tested on one device only: a Pixel 3a running Ubuntu Touch 24.04-1.x.

## New since 0.0.10

- "Information" in a video's menu opens a page about it: its picture and
  name, a button to play or resume it, its length, file size, resolution,
  format, file and folder, when it was last changed, and how far it was
  played. With one video selected, the bar at the top has a button for it
  too.
- The diagnostics page no longer plays test streams from the internet.
  Nothing in the app touches the network now.
- A video's menu is now in VLC's order: Information and the favourite switch
  come before the group entries, and "Mark as played" is last.

Nothing in the player itself has changed.

## Network

GemPlayer is being built to do nothing over the network except play a stream
whose address you give it, and that feature is not built yet. So this build
makes no connection of any kind. It will have no network shares, no casting,
no remote control, and will look nothing up online.

## What it does

- Lists the videos on the phone, as a grid or a list, and plays H.264, HEVC,
  VP9 and AV1.
- Sorts the list by name, file name, length or how recently a file was
  added, filters it as you type, groups it by name or by folder, and can show
  only your favourites.
- Lets you make groups of your own, rename them and dissolve them.
- Plays a folder, a group, a selection or the whole list in order.
- VLC's gestures: tap for the controls, double tap to skip 10 s or pause,
  swipe sideways to seek, swipe up and down for volume (right half) and
  brightness (left half), pinch to fill the screen.
- **Play as audio**, and back to video, without a break in playback. Audio
  carries on with the screen off and under other apps.
- Resumes each file where it was left.
- Sleep timer, jump to time, A-B repeat, bookmarks, screenshot.
- Shows a `.srt` subtitle file that sits beside the video, with a delay
  control.
- Twelve picture sizes, a lock, and its own rotation, whatever the system's
  rotation lock says.
- Opens files handed over by other apps.
- VLC's five tabs along the bottom. Audio, Browse and Playlists are empty for
  now and say what is to come.

## Before you install

- **The app is unconfined.** It runs outside Ubuntu Touch's sandbox, because
  the system does not let a sandboxed third-party player open the files in
  Music and Videos. It reads media files and writes only its own settings.
  `docs/STORE.md` has the details.
- The package also contains two development aids: a diagnostics page (More →
  Diagnostics) and a remote control that stays off unless a marker file is
  created by hand. Both are removed before 0.1.0.

## Known limits

- No playback speed, no choice of audio track, no embedded subtitles. The
  system's playback service does not offer them.
- A seek lands on the keyframe before the place asked for, so seeking,
  resume, bookmarks and A-B repeat can start a few seconds early.
- The sleep timer and A-B repeat run only while the app is on screen. With
  the screen off the timer fires late, when the app is next opened.
- A queue played as audio does not move on while the screen is off or
  another app is in front: the current video plays to its end, and the next
  starts when GemPlayer is opened again.
- The queue cannot be changed once it plays: nothing can be added to it,
  removed or reordered, and there is no shuffle or repeat yet.
- The system's media controls show the playing file under the name "Media
  Player".
- A clip shorter than about 20 s never shows a progress bar: its first 10 s
  count as not started and its last 10 s as finished.
- "Recently added" goes by the date a file was last changed; the system's
  library does not record when a file arrived.
- Groups of your own exist only under "Group by name"; with "Group by
  folder" or no grouping they are kept but not shown.
- The information page shows a video's resolution as a class (1080p, SD),
  not in pixels, and lists no tracks or codecs: the system reports neither
  reliably.

## Install

```bash
adb push gemplayer.yenis_0.0.11_all.click /home/phablet/
adb shell "pkcon install-local --allow-untrusted /home/phablet/gemplayer.yenis_0.0.11_all.click"
```

The phone needs Developer Mode on. It installs over an earlier build and
keeps its resume points, bookmarks, favourites and groups. `docs/INSTALL.md`
has the full steps, and how to remove the app again.
